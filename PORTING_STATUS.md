# Porting status — Python → Node.js

Legend: **ported** = full behaviour ported · **golden-tested** = ported and
byte-compared against the Python original · **partial** = main path ported,
some branches differ (see notes) · **stubbed** = interface exists, behaviour
not implemented (see notes).

Source deviations found while porting (source wins over any secondary doc):
- Unauthorized bridge requests get **401** (not 403), with an empty body.
- The token header is **`X-PT-Token`** (not `X-Bridge-Token`).
- `/next` long-poll is **2.0 s**; results are correlated per-`rid` via
  `GET /result?rid=…&wait=…`; there is no `/last-result` or `/favicon` route.
- The live server registers **98 tools** (the docs page says 96; the tool-API
  snapshot and a live `tools/list` both say 98).

Sanctioned difference: `PT_MCP_BRIDGE_HOST` env var (bind address + Host
allowlist entry). Default unset ⇒ identical to upstream.

### Bugs found by differential testing and fixed

- **IPv6 group reversal (shared/ipnet.js)**: formatIPv6/IPv6Address.exploded
  extracted groups in reverse order ("2001:db8::1" → "1::db8:2001"),
  corrupting every dual-stack string. Found independently by the domain and
  services clusters; fixed; IPv6 compressed/exploded/network output now
  matches Python exactly, and a dual-stack pt_plan_topology call is
  byte-identical end to end.
- **remove_nat_uc calling convention**: it passed an options object to the
  positional build_nat_remove_payload, producing "interface undefined" in
  pt_remove_nat payloads. Found by the tools cluster's 97-scenario harness
  (its only real diff). Fixed to the positional call; two golden regression
  cases added; pt_remove_nat (pat + static) now byte-identical.

### Known fidelity notes

- **Catalog iteration order**: JS objects iterate integer-like keys
  numerically, Python dicts by insertion. ALL_MODELS / MODEL_ALIASES carry
  explicit `*_ORDER` arrays; pt_list_devices and the two catalog resources
  serialize in Python order (verified byte-identical). Other dicts with
  integer-like keys (e.g. an STP `priority` map given out of order) can
  iterate in numeric rather than insertion order — same content, possibly
  different key order in JSON text.
- **Bridge `/status` floats**: `last_poll_ago` is emitted via pyRound/PyFloat
  so integral values print as `0.0` like Python.
- ui_mode's store is async (the Python original lazily imports the token
  dir; the port resolves it with a dynamic import).
